# 📊 DSA Progress Tracker

A web-based application to help users **track their DSA progress across multiple dsa sheets** and calculate the **total number of unique problems solved**, even if the same problem appears in multiple sheets.

---

## 🚀 Features

* 📚 Track progress across multiple DSA sheets
* ✅ Count **unique solved questions** only once
* 📊 View progress sheet-wise and overall
* 🔁 Avoid duplicate problem counting
* 🧠 Clean and easy-to-use interface
